# Security policy

## Private vulnerability reporting

Do not report vulnerabilities through public GitHub issues, pull requests,
discussions, or social media.

## GitHub Security Advisories

Use **Report a vulnerability** in this repository's GitHub Security tab.

## security@mcplama.com

You may also report vulnerabilities privately by emailing
[security@mcplama.com](mailto:security@mcplama.com).

## Required report details

Include:

- vulnerability description and impact;
- affected versions and deployment configuration;
- reproduction steps or a proof of concept; and
- relevant logs or screenshots without secrets or personal data.

## Response process

Maintainers will acknowledge reports within five business days, investigate
the issue, communicate progress, and coordinate a fix or security advisory.

## Safe-harbor rules

Good-faith research is welcome when it avoids accessing private data, disrupting
services, destroying data, deploying persistence, or testing systems without
authorization. Stop testing and report immediately if you encounter data or
systems outside your authorization.

## Scope and exclusions

This policy covers MCPlama source code, official images, and official
deployment documentation. Third-party MCP servers, registries, hosting
providers, and user-operated infrastructure are outside this policy's scope.
